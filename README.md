# 🤖 AI Pribadi - DeepSeek Clone

Aplikasi AI Pribadi dengan tampilan mirip DeepSeek menggunakan Google Gemini API.

## ✨ Fitur

- 💬 **Chat Real-time** dengan AI Gemini
- 🎨 **Tampilan Modern** mirip DeepSeek
- 🔧 **Custom Prompt** untuk mengatur perilaku AI
- 🌡️ **Pengaturan Kreativitas** (Temperature)
- 📱 **Responsive Design** untuk semua perangkat
- 💾 **Riwayat Chat** tersimpan di localStorage
- 🔒 **API Key** disimpan secara lokal
- 🎯 **Multi-model** support (Flash, Pro, 1.0 Pro)

## 📋 Prasyarat

1. **API Key Google AI Studio**
   - Dapatkan di: [Google AI Studio](https://aistudio.google.com/apikey)
   - Gratis dengan kuota 60 request/menit

2. **Browser Modern** (Chrome, Firefox, Safari, Edge)
